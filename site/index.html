别在生产环境手滑

同一套后台开三个环境，颜色长得一模一样。EnvMark 会按你配置的规则判断当前站点，在页面上打一个 一眼就能看见的标记——生产环境套红框，测试环境套琥珀框。

生产环境

四种标记方式

边框、顶部条、角标、水印。从「不挡任何内容」到「很难忽略」，按自己的接受度选。

判定优先级明确

手动指定 → 你的规则 → 页面声明 → 关键词。规则支持通配符、URL 片段和正则。

不做误判

关键词识别刻意保守，只有域名里明确写了 prod 才判定生产，不会到处乱套红框。

数据不出浏览器

没有账号、没有服务器、没有埋点。所有判断都在本地完成，只申请了 storage 权限。

怎么安装

还没上架应用商店，目前从源码构建，两步搞定。

  1. 克隆仓库并安装依赖：git clone https://github.com/Air1996/env-mark.git 后执行 npm install
  2. 构建：npm run build，产物在 .output/chrome-mv3
  3. 打开 chrome://extensions，开启右上角「开发者模式」，点「加载已解压的扩展程序」，选中刚才那个目录
