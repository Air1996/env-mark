# 上架 Chrome Web Store 资料

这份文件里的文案可以直接粘贴到 [开发者控制台](https://chrome.google.com/webstore/devconsole) 的对应字段。素材在 `store/` 目录下。

---

## 一、账户相关（一次性）

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| Google 账号 | 可长期登录 | 会用来收审核结果，别用小号 |
| 开发者注册 | 一次性 5 美元 | 付一次，账号终身有效，可发布多个扩展 |
| 两步验证 | **必须开启** | 没开 2SV 无法提交，先去 Google 账号安全设置里打开 |

付款要能走国际线上支付的卡，以付款页实际支持的卡种为准。

## 二、上传包

```
.output/env-mark-1.1.0-chrome.zip
```

zip 根目录必须直接是 `manifest.json`（WXT 已经处理好）。以后每次更新只需把 `package.json` 的 `version` 调大 → 重新 `npx wxt build && npx wxt zip` → 上传新 zip。

## 三、商店信息（可直接复制）

**名称**（上限 45 字符）

```
EnvMark — 环境标记
```

**简短说明**（上限 132 字符）

```
在页面上标记当前站点是开发、测试还是生产环境。一眼分辨，避免在测试时误操作线上数据。
```

**详细说明**

```
同一个后台，测试域名和生产域名长得几乎一样，改错一次就够难受一天。EnvMark 在页面上给你一个不会被忽略的提示。

■ 它能做什么
• 自动判断当前站点属于哪种环境，并在页面上标记出来
• 四种标记方式：边框、顶部条、角标、水印，存在感从轻到重，边框 / 顶部条 / 水印的透明度各自可调
• 角标可以直接在页面上拖动，拖到顺手的位置就会记住
• 界面支持中文与 English，默认跟随浏览器语言
• 工具栏图标显示 P / T / D / L 角标，不点开也知道当前环境
• 设置一次，这个域名以后都记住

■ 判定顺序
手动指定 → 自定义规则 → 网页自身声明 → 关键词识别

• 网页声明：识别 <meta name="env" content="staging">、<html data-env="prod">、window.__ENV__
• 自定义规则：通配符 *.test.example.com、URL 片段 :8080 或 /preview/、正则表达式三种写法，从上到下先命中先用
• 关键词识别刻意保守：只有域名里出现 prod / production / prd 才判定为生产，不会把普通网站误判成线上环境

■ 适合谁
在多个环境之间来回切换的前端、后端、测试同学，以及任何需要在后台手动改数据的人。

■ 隐私
不需要登录，没有账号系统，不向任何服务器发送数据。所有判断都在你的浏览器里完成，规则和设置只存在本地。
```

**类别**：开发者工具（Developer Tools）
**语言**：中文（简体）
**主页 / 支持链接**：可填 GitHub 仓库地址，留空也不影响审核

## 四、隐私标签页（Privacy practices）

这一页是审核重点，逐项照抄：

**单一用途说明**

```
在网页上以可视化的方式标记当前站点所属的环境（开发 / 测试 / 生产），帮助用户在操作后台数据前确认自己没有弄错环境。
```

**权限理由**

`storage`

```
保存用户自己配置的环境规则、标记样式、角标开关等设置。数据仅写入 chrome.storage.local，不离开本机。
```

`访问所有网站的权限`（由 content_scripts 的 <all_urls> 声明）

```
扩展的功能是在用户所访问的网页上叠加一层很薄的标记（边框 / 顶部条 / 角标 / 水印），因此无法预先枚举域名，只能声明全站匹配。内容脚本在本地读取当前页面的 URL、<html> 标签属性、<meta> 标签以及页面自身可能写入的 window.__ENV__，用于判断环境；不读取页面正文、表单内容或 Cookie，不做任何网络请求，也不注入远程代码。
```

> 只勾选了 `storage` 这一项权限，`tabs` / `cookies` / `webRequest` / `history` 都没有申请。全站匹配属于会触发人工深审的项，审核时间可能比普通扩展长一些，属正常。

**远程代码**

```
否，我没有使用远程代码
```

（所有逻辑都在打包产物内，没有 eval，不加载远端脚本。）

**数据使用**

- 数据收集：**全部不勾选**（不收集个人身份信息、健康、财务、身份验证、通讯、位置、网页历史、用户活动、网站内容）
- 三项认证全部勾选：不出售给第三方 / 不用于与单一用途无关的目的 / 不用于判断信用度或放贷

**隐私政策网址**

必须是一个公网可访问的页面（私有仓库里的文件不算）。已部署到 GitHub Pages，直接填：

```
https://air1996.github.io/env-mark/privacy.html
```

源文件在 `store/privacy.html`，发布用的是 `site/privacy.html`，两者改一处记得同步。

## 六、提交之后

1. 上传 zip → 填商店信息 → 填隐私标签页 → 保存草稿
2. 分发设置里选可见性（公开 / 不公开列出）和地区（默认全部）
3. 点「提交审核」。首次提交走人工，通常几小时到几天；申请了全站权限的会慢一些
4. 审核期间邮箱保持可收信，被拒会写明原因，改完重新提交即可，不额外收费

常见被拒原因，本项目都已规避：权限超出功能所需、缺少隐私政策、描述堆关键词、MV3 下加载远程代码、商店文案与实际功能不符。
